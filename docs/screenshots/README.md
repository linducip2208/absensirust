# Screenshots

Belum ada tangkapan layar — sesi build ini non-interaktif (tanpa desktop),
sehingga screenshot jendela aplikasi tidak dapat diambil di sini
(tidak direkayasa/dipalsukan).

Cara mengambil (pada Windows interaktif):

1. Jalankan `AttendX Rust` (atau `cargo run` dari `src-tauri`).
2. Ambil tangkapan tiap layar utama dan simpan di folder ini:
   - `01-setup-admin.png` — pembuatan admin pertama
   - `02-login.png`
   - `03-dashboard.png`
   - `04-karyawan.png` (+ `05-import-csv.png`)
   - `06-shift.png`, `07-absensi.png`, `08-perangkat.png`
   - `09-laporan.png`, `10-backup.png`
3. Jangan sertakan data karyawan asli / NIK nyata pada screenshot publik.
